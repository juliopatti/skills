# Skills do Claude Code

Skills pessoais, versionadas aqui e linkadas em `~/.claude/skills/` para ficarem disponíveis em qualquer projeto.

| Skill | Uso | Descrição |
|---|---|---|
| `iniciar-projeto` | `/iniciar-projeto <ideia>` | Inicia um projeto de software: briefing CO-STAR, MVP, arquitetura Mermaid, Git e scaffold testável. |

## Instalar uma skill

```bash
ln -s ~/Documentos/projs/skills/<nome> ~/.claude/skills/<nome>
```
